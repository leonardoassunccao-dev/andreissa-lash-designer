# Andreissa Lash Designer

Site oficial, portfólio e catálogo digital de Andreissa Ferreira, Lash Designer em Barrinha/SP.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm start
```

Defina `NEXT_PUBLIC_SITE_URL` com o domínio final para canonical, sitemap e metadados sociais.
